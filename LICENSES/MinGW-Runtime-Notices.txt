MinGW-w64 / GCC runtime components shipped with this distribution
=================================================================

The following compiler runtime DLLs are deployed alongside the
application (installed by Qt's windeployqt with --compiler-runtime):

  libgcc_s_seh-1.dll   GCC runtime support library
  libstdc++-6.dll      GNU Standard C++ library
  libwinpthread-1.dll  MinGW-w64 POSIX threads library (if present)

libgcc_s_seh-1.dll and libstdc++-6.dll are part of GCC and are licensed
under the GNU General Public License version 3 with the GCC Runtime
Library Exception (see GPL-3.0-only.txt in this folder and the
exception text below). Dynamic linking of an executable against these
libraries, and distribution of the binaries, is permitted under the
exception's terms.

libwinpthread-1.dll is part of the MinGW-w64 project runtime and is
distributed under a permissive license (MIT-style, see the MinGW-w64
project for the full text).
